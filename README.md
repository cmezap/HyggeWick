# HyggeWick

HyggeWick es una aplicación personal de lectura digital. Su objetivo es ofrecer una experiencia de lectura enfocada y funcionar offline-first, priorizando el uso local.

## Tecnologías

- Expo SDK 58 y Expo Router
- React 19 y React Native 0.88
- TypeScript 6 con modo estricto

## Desarrollo

Requisitos básicos: Node.js, npm y un dispositivo Android con Expo Go o una compilación de desarrollo compatible.

Instala las dependencias:

```bash
npm install
```

Inicia Expo:

```bash
npx expo start
```

Para probar en un dispositivo Android físico, instala Expo Go (o la compilación de desarrollo correspondiente), conecta el teléfono y el equipo a la misma red, escanea el código QR que muestra Expo y abre el proyecto.
